# TendaPhoneControl 1.3

Android-приложение для локального управления Tenda F3. Во время обычного использования ПК не нужен.

## Фон
Основные динамические режимы запускаются через Android foreground service типа `connectedDevice`. При погашенном экране они продолжают выполняться, если система не ограничила приложение. Конфигурация и время окончания сохраняются. Есть попытка возобновить сохранённый режим после перезагрузки Android.

Для надёжности нужно исключить приложение из оптимизации батареи и на телефонах с агрессивным энергосбережением убрать его из списка спящих/глубоко спящих приложений.

## Жёсткое ограничение
Если телефон полностью выключен (Power OFF), приложение физически не выполняется. Поэтому хаос/волна/мерцание не могут продолжаться во время полного выключения телефона. После загрузки Android сохранённый режим может возобновиться.

Настоящее 24/7 выполнение при выключенном телефоне требует другого постоянно включённого контроллера.

## Режим работы

- Экран выключен/приложение свернуто: фоновые режимы продолжают работать через foreground service, пока Android не остановил службу.
- Перезагрузка телефона: сохранённый режим пытается стартовать снова через `BOOT_COMPLETED`.
- Полное выключение телефона: выполнение невозможно до следующего запуска Android.
- Если нужно, чтобы режим шёл даже при полностью выключенном телефоне, приложение должно выполняться на другом включённом устройстве.

## Изменения 1.3
- Исправлена ошибка компиляции (дубликат `Prefs.label`), из-за которой проект не собирался.
- Добавлены Gradle wrapper (`./gradlew`), иконка приложения, иконка уведомления, `.gitignore`.
- Разрешение `POST_NOTIFICATIONS` (Android 13+) + запрос при первом запуске.
- Службе добавлены WakeLock и WifiLock — режимы стабильнее работают при погашенном экране.
- Кнопка «Стоп» прямо в уведомлении.
- Запуск нового фонового режима поверх работающего больше не теряет исходные лимиты и применяет новые интервал/длительность.
- Повторный вход в Tenda, если сессия роутера истекла или Wi‑Fi ещё не поднялся после перезагрузки (ожидание до 3 минут).
- Корректные отступы под статус-бар/навигацию (Android 15, edge-to-edge).
- Workflow GitHub Actions собирает через `./gradlew`.

> Не проверено на реальном роутере: селекторы страницы Tenda F3 (поиск `select`, кнопок «Сохранить/ОК») написаны под конкретную прошивку; при другой вёрсте может понадобиться подстройка.
