# Сборка APK на ноутбуке/ПК — самый простой способ

1. Установи актуальный Android Studio. На Windows официальный минимум сейчас — 64-bit Windows 10 и 8 GB RAM для самого Studio; эмулятор этому проекту не нужен.
2. Распакуй ZIP.
3. Android Studio → **Open** → выбери папку `TendaPhoneControl`.
4. Дождись Gradle Sync и установи предложенные SDK/Build Tools.
5. **Build → Build APK(s)**.
6. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.
7. Передай APK на телефон и установи.

После установки Android-телефон и Tenda F3 должны быть в одной локальной сети.
