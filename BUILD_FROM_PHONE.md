# Сборка APK только с Android-телефона

Через GitHub Actions:
1. Создай приватный GitHub repository.
2. Загрузи содержимое папки `TendaPhoneControl`.
3. Открой **Actions → Build APK → Run workflow**.
4. После завершения открой run → **Artifacts → TendaPhoneControl-debug**.
5. Скачай APK на телефон и установи.

Само приложение после установки работает без ПК.
